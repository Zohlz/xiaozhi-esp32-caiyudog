# 菜鱼狗 · caiyu-dog

[中文] | [English](README.md) | [日本語](README_ja.md)

## 1. 项目介绍

菜鱼狗是一只**高颜值四足桌宠机器狗**。它在小智（XiaoZhi）语音助手的基础上，加了四条舵机腿、两条条 WS2812 灯带和一枚触摸按键：ESP32-C3 负责语音与显示，128x64 OLED 当脸（一双会眨眼的几何大眼睛），四条腿负责站立、坐下、走路、跳舞。

整个工程只保留这一个板卡实现 **`caiyu-c3`**，其它板卡都已删掉。

**具体玩法：详细功能分析**

- **语音对话**：ESP-SR 离线唤醒，触摸一下开始 / 结束对话；唤醒时它会先站起来
- **表情**：21 种几何大眼睛；待命时自动「睡觉」（眼睛半闭、呼吸起伏、飘 Zzz）
- **四足动作**：站立 / 坐下 / 趴下 / 走路 / 前进后退 / 左右转 / 挥手 / 伸懒腰 / 摇摆跳舞 / 挠痒 / 抖后腿，语音或网页都能指挥
- **对话小动作**：说话时按情绪配一点小动作（点头、晃晃、撅屁股…），不打断正式动作
- **灯带**：常亮 / 呼吸 / 彩虹 / 流水 / 闪烁，颜色、亮度、速度都能调
- **手机控制页**：设备连上 Wi-Fi 后浏览器打开 `http://<设备IP>/`；或者长按触摸 1 秒，屏幕上显示二维码，扫码直接进
- **舵机微调**：网页「设置」页给四条腿各 ±20° 校正，保存进设备 NVS

## 2. 组装连线

### 2.1 DIY 所需硬件

- **开发板**：ESP32-C3 SuperMini（4MB Flash）
- **数字麦克风**：INMP441 / ICS43434
- **功放**：MAX98357A
- **腔体喇叭**：8Ω 2~3W 或 4Ω 2~3W
- **显示**：SH1106 OLED，128x64，I2C 接口
- **触摸模块**：TTP223 类（**必须 3.3V 供电**）
- **灯带**：WS2812 / WS2812B，4 颗
- **舵机**：180° 舵机 ×4（SG90 / MG90S 类）
- **电阻**：2kΩ ×1（串在触摸支路上做限流保护）
- **Type-C 数据线** + 一台能烧固件的电脑

除此之外，你可能还需要：万用表、电烙铁套件。

### 2.2 接线对照表

| 功能 | GPIO | 说明 |
| --- | --- | --- |
| 麦克风 WS / SCK / DIN | 7 / 6 / 5 | I2S 输入 |
| 功放 LRCK / BCLK / DOUT | 4 / 3 / 2 | I2S 输出 |
| OLED SDA / SCL | 8 / 9 | I2C，地址 0x3C |
| 触摸按键 + 灯带 DIN | 0 | **共用一根线**，分时复用 |
| 左前腿舵机 | 1 | LEDC 驱动 |
| 右前腿舵机 | 10 | LEDC 驱动 |
| 左后腿舵机 | 20 | LEDC 驱动 |
| 右后腿舵机 | 21 | LEDC 驱动 |

**接线注意：**

1. **舵机不要从开发板取电**：4 个舵机一起动峰值电流能到 1.5A 以上，必须用独立电源，并且**和开发板共地**（GND 连在一起）。
2. **触摸模块必须 3.3V 供电**：接 5V 时 OUT 会输出 5V，超出 ESP32-C3 的输入耐压，可能烧芯片。
3. **保护电阻只串在触摸支路**：2kΩ 不要串在灯带数据线上，否则会破坏 WS2812 的 800kHz 时序。
4. **GPIO20 / GPIO21 同时是 C3 的 UART0 默认引脚**：接上舵机后请看 USB（Serial/JTAG）口的日志 —— 如果开发板只有板载 USB 转串口，日志会因为引脚被舵机占用而看不到。
5. **GPIO8 / GPIO9 是芯片的 strapping 引脚**，也是不少 C3 板载 WS2812 的引脚：用它们接 OLED 时，板载灯可能跟着 I2C 通信闪一下，属正常现象。

### 2.3 机械安装与校准

四条腿按对角对称装好即可（左前 / 右前 / 左后 / 右后）。代码里右侧两条腿做了镜像，所以「两条前腿都往前伸」在代码里是同一个角度值。

舵机臂没卡正、左右装得不对称，都不用改代码：进控制页的「设置」标签页，拖四条腿的微调滑块调到正，再点「保存到设备」写进设备，重启后依然生效。

## 3. 固件烧录

### 3.1 本地烧录（ESP-IDF）

需要 ESP-IDF **v6.0.2**：

```sh
source /path/to/esp-idf/export.sh

python scripts/build.py caiyu-c3      # 配置 + 编译
idf.py -p <串口> flash monitor        # 烧录并看串口日志
```

设备连上 Wi-Fi 后，日志里会打印控制页地址：

```text
I (1234) CaiyuC3Board: control page: http://192.168.1.23/
```
